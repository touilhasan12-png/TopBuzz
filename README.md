# TopBuzz

A Godot 2D animation test inspired by the user's `videotest` reference.

- Source scene and art: [`ENGINE_SOURCE/`](ENGINE_SOURCE/)
- Test criteria: [`ENGINE_SOURCE/TEST_PLAN.md`](ENGINE_SOURCE/TEST_PLAN.md)
- On GitHub: open **Actions → Render Godot test shot → Run workflow** to render an 8-second portrait MP4.

The sample is a technical/art-direction proof of concept, not a complete 75-second recreation. The art assets are newly created for this project and do not reuse the source video's frames.
