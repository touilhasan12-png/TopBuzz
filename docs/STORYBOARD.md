## Visual continuity rules
- Keep the strait in a consistent orientation so transitions remain legible.
- Use the same camera-space landmark anchors for each era.
- Use short, readable chapter titles; use subtitles only if requested/approved.
- Any reconstructed battle/urban change is clearly illustrative, not presented as documentary footage.
